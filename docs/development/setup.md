# Setup

_For contributors setting up GlyphSpace on their machine._

## Requirements

| Tool | Version | Used for |
|---|---|---|
| Node.js | 26 (`.nvmrc`; `package.json` accepts `>=26.0.0`) | the app, its tests and tooling |
| npm | the one that ships with Node (11.20 with Node 26.13) | dependencies (`package-lock.json`); older npm versions can drop entries that newer ones require, so update the lock file with a current npm |
| Python | 3.10 or newer, with `pandas`, `numpy`, `scikit-learn`, `umap-learn` and `pytest` | only for `tools/` (bundled datasets, Python tests) |

The repository has no Python requirements file; install the packages above into the environment you use for `tools/`.

## First run

```bash
npm ci                            # install exactly what package-lock.json lists; also installs the git hooks
npx playwright install chromium   # once per machine: the browser the unit tests run in
npm start                         # dev server at http://localhost:4200/
```

Each Playwright version uses its own Chromium build. When an update of `package-lock.json` brings a new Playwright version, run `npx playwright install chromium` again.

The app loads the bundled datasets from `src/assets/data/` on start. At the same time the Pyodide worker starts downloading Pyodide, pandas and scikit-learn from the jsDelivr CDN in the background; the wizard needs them, so importing needs network access.

## Scripts

| Command | What it does |
|---|---|
| `npm start` | `ng serve`, dev server with reload |
| `npm run build` | production build into `dist/glyphspace/` |
| `npm run watch` | development build, rebuilt on change |
| `npm test` | unit tests in watch mode ([Testing](testing.md)) |
| `npm run test:ci` | unit tests once |
| `npm run lint` | ESLint over `src/**/*.ts` and `src/**/*.html` |
| `npm run format` / `format:check` | Prettier over `src/**/*.{ts,html,scss,json}` |
| `python tools/process.py <file.csv>` | add a bundled dataset ([Preparing data](../user-guide/preparing-data.md)) |
| `python tools/process.py` | regenerate `src/default-dataset.ts` from the files in `src/assets/data/` |
| `python -B -m pytest -p no:cacheprovider tools/tests` | Python tests |

Run the Python commands from the repository root. On Windows, `tools/process.py` imports `umap` before numpy, pandas and scikit-learn on purpose: otherwise llvmlite's DLL fails to load (WinError 1114).

## Git hooks

`npm ci` runs `husky` (the `prepare` script), which installs `.husky/pre-commit`. It runs `lint-staged` on the staged files: `eslint --fix` and `prettier --write` for `src/**/*.{ts,html}`, `prettier --write` for `src/**/*.{scss,json}`. Files outside `src/` (docs, Python) are not checked by the hook.

## Repository layout

| Path | Contents |
|---|---|
| `src/app/` | the Angular app ([Architecture](architecture.md)) |
| `src/assets/data/` | bundled datasets ([Dataset format](../specs/dataset-format.md)) |
| `src/assets/*.py` | the wizard's Python pipeline, loaded into Pyodide at runtime |
| `src/assets/samples/` | the sample CSV offered in Step 1 |
| `src/assets/thumbnails/<dataset>/` | thumbnail images of bundled datasets, `<id>.jpg` |
| `src/default-dataset.ts` | the list of bundled datasets, generated by `tools/process.py` |
| `src/licenses/` | licence texts and the third-party notice, published as `licenses/` |
| `src/styles/` | SCSS tokens (`_variables.scss`) and mixins |
| `src/testing/`, `src/test-setup.ts` | shared test helpers and the per-test setup |
| `tools/` | the CLI for bundled datasets, the sample-data generator, the Python tests |
| `docs/` | this documentation ([index](../README.md)) |
| `CLAUDE.md` | guidance for Claude Code: where the docs are, the architecture in brief, the commands |
| `.github/workflows/deploy.yaml` | CI and deployment ([Deployment](deployment.md)) |
