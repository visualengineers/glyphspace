About GlyphSpace

GlyphSpace shows datasets as glyphs placed by dimensionality reductions. It runs entirely in your browser and is open source under the MIT licence: source code.

Data

The bundled wineqr dataset and the wizard's sample file are based on Wine Quality by P. Cortez, A. Cerdeira, F. Almeida, T. Matos and J. Reis, UCI Machine Learning Repository, licensed under CC BY 4.0. Modified: GlyphSpace uses the red wines, adds an ID to each, and derives normalised features and projections.
